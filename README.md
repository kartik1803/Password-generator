# Password Generator 🔐

A responsive password generator built using HTML, CSS, and JavaScript that helps users create strong, random passwords based on their preferences.

## ✨ Features

- **Custom Password Length:** Choose a password length between 1 and 20 characters.
- **Character Selection:** Include uppercase letters, lowercase letters, numbers, and symbols.
- **Password Strength Indicator:** Visually displays password strength.
- **Copy to Clipboard:** Quickly copy generated passwords.
- **Responsive Design:** Works across different screen sizes.
- **Dark UI:** Modern interface with gradient backgrounds and interactive elements.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/kartik1803/Password-generator.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
